# Guild Bounty Forever 1.0.0

Copy this entire GuildBountyForever folder into _forever_/Interface/AddOns/.
Enable the addon and restart the client for a new installation, or /reload for an update.
Open with /gbf. Complete the interactive first-launch tour; replay it with /gbf help.

Full screenshots, feature demos and documentation:
https://github.com/IronfoeStormhammer/guild-bounty-forever

Target: World of Warcraft Forever 1.60.1, interface 16001.
Guild membership is required for sharing; unguilded listings are local.
COD preparation requires an open mailbox and an explicit Prepare delivery click.
Always review the native draft and manually click Send. No gold is escrowed.

The bottom-right heart offers thanks or one of 100 playful Azerothian roasts.
No real-money donations are requested.
